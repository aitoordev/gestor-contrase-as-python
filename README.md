# GESTOR DE CONTRASEÑAS

Este proyecto lo he hecho porque estaba harto de utilizar la aplicación de notas para guardar mis contraseñas.

Con este programa puedo guardar y consultar mis contraseñas de una forma más ordenada, almacenándolas localmente en mi ordenador.

## EJECUTAR

```bash
python main.py
```

## FUNCIONES

- Guardar contraseñas
- Consultar contraseñas
- Guardar los datos localmente
- Interfaz sencilla mediante terminal

## TECNOLOGÍAS

- Python
- JSON
